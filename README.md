## 2. Deskripsi Program untuk Responsi

ARD Hospital merupakan program simulasi rumah sakit berbasis Java yang menerapkan konsep Pemrograman Berorientasi Objek (PBO).

Program menyediakan fitur pendaftaran pasien, pemeriksaan oleh dokter, pemberian obat, pembayaran, dan pengelolaan status pasien.

## 3. Petunjuk Compile dan Run

### A. Persyaratan

Sebelum menjalankan program, pastikan perangkat telah memiliki:

1. **Java Development Kit (JDK)** untuk melakukan kompilasi dan menjalankan program Java.
2. **IntelliJ IDEA** sebagai Integrated Development Environment (IDE) untuk membuka, mengelola, dan menjalankan kode program.
3. **Repositori** yang telah diunduh dari GitHub.

### B. Mengunduh Project dari GitHub

1. Buka repositori GitHub yang berisi source code.
2. Klik tombol **Code**.
3. Pilih **Download ZIP** untuk mengunduh seluruh source code.
4. Setelah proses unduh selesai, ekstrak file ZIP ke direktori yang diinginkan.
5. Pastikan folder hasil ekstraksi berisi source code program.

### C. Membuka Project di IntelliJ IDEA

1. Jalankan aplikasi IntelliJ IDEA.
2. Pada halaman awal, pilih **Open**.
3. Cari dan pilih folder project yang telah diekstrak sebelumnya.
4. Tunggu hingga IntelliJ IDEA selesai memuat project.
5. Pastikan file-file Java di dalam package sudah terbaca oleh IntelliJ IDEA.

### D. Mengatur JDK

Jika IntelliJ IDEA belum mendeteksi JDK secara otomatis, lakukan pengaturan berikut:

1. Buka menu **File → Project Structure**.
2. Pilih bagian **Project**.
3. Pada bagian **SDK**, pilih JDK yang telah terpasang.
4. Jika belum tersedia, pilih **Add SDK → Download JDK** atau tambahkan lokasi JDK yang sudah terpasang.
5. Klik **Apply**, kemudian **OK**.

### E. Menjalankan Program

1. Pada panel Project, buka package `Responsi`.
2. Cari dan buka file `Main.java`.
3. Pastikan file tersebut memiliki method `public static void main(String[] args)`.
4. Klik ikon segitiga hijau di sebelah deklarasi method `main`, kemudian pilih **Run 'Main.main()'**.
5. IntelliJ IDEA akan melakukan proses kompilasi secara otomatis dan menjalankan program.
6. Hasil eksekusi akan ditampilkan pada jendela **Run** di bagian bawah IntelliJ IDEA.

### F. Menggunakan Program

Setelah program berhasil dijalankan, menu utama ARD Hospital akan ditampilkan pada jendela Run.

Pengguna dapat memasukkan nomor menu melalui kolom input untuk memilih fitur yang tersedia, seperti pendaftaran pasien, melihat daftar pasien, pemeriksaan pasien, pembayaran, melihat daftar dokter, dan informasi rumah sakit.

Untuk menjalankan fitur tertentu, masukkan nomor pilihan sesuai menu yang ditampilkan, kemudian tekan **Enter**.

### Catatan

- Seluruh proses kompilasi dan eksekusi dapat dilakukan langsung melalui IntelliJ IDEA tanpa perlu menjalankan perintah melalui terminal.
- Pastikan JDK telah terpasang dan terkonfigurasi dengan benar agar program dapat dijalankan.
- Jika terjadi kesalahan saat menjalankan program, periksa kembali konfigurasi JDK, struktur package, dan source code.
